## [Circle](..//circle.py) 
- Area
```python
def area(r):
    '''Принимает значение радиуса круга и возвращает его площадь'''
    return math.pi * r * r
```
```
пример вызова
значение r: 1
функция вернет: 3.141592653589793
```
- Perimetr
```python
def perimeter(r):
    '''Принимает значение радиуса круга и возвращает длину его окружност'''
    return 2 * math.pi * r
```
```
пример вызова
значение r: 1
функция вернет: 6.283185307179586
```

## [Parallelogram](..//parallelogram.py)
- Area
```python
def area(a, aH):
    '''Принимает значения стороны и высоты, проведенной к данной стороне, и возвращает его площадь'''
    return a * aH
```
```
пример вызова
значения a и aH: 2 5
функция вернет: 10
```
- Perimetr
```python
def perimeter(a, b):
    '''Принимает значение двух сторон параллелограма и возвращает его периметр'''
    return (a + b) * 2
```
```
пример вызова
значения a и b: 3 7
функция вернет: 48
```
## [Trapezoid](..//trapezoid.py)
- Area
```python
def area(a, b, h):
    '''Принимает значения оснований трапеции и ее высоту и возвращает площадь фигуры'''
    return (a + b) * 0.5 * h 
```
```
пример вызова
значения a, b, h: 3 7 10
функция вернет: 50
```
- Midline
```python
def midline(a, b):
    '''Принимает значения оснований трапеции и возвращает ее среднюю линию'''
    return (a + b) * 0.5
```
```
пример вызова
значения a, b: 7 5
функция вернет: 6
```
