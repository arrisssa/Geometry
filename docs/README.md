## Формулы
### Circle  
-Area: S = πR<sup>2</sup>
-Perimetr: P = 2πR
### Square
-Area: S = a<sup>2</sup>
-Perimetr: P = 4 * a
### Parallelogram
-Area: S = a * aH
-Perimetr: P = 2 * (a + b)
### Trapezoid
-Area: S = (a + b) * 0.5 * h
-Midline: M = (a + b) * 0.5
